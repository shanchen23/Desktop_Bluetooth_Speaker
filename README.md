# 基于 STM32 的桌面环境管家（桌面蓝牙音响）
## 一、项目概述
本项目设计并实现了一款基于 STM32F103C8T6 单片机的桌面多功能终端，集环境监测、蓝牙音乐播放、实时时钟、电量显示、水平仪等功能于一体，并配备中文图形界面与多级菜单，实现"一屏多用"的桌面管家体验。项目由本人独立完成，涵盖硬件选型、原理图与 PCB 设计、底层驱动开发、应用逻辑编写到整机联调的完整流程。

## 二、硬件设计
使用立创EDA完成原理图与 PCB 设计，主要模块包括：

主控：STM32F103C8T6；
显示：SPI 彩色液晶屏，外挂 W25Q64 Flash 存储中文字库与 Unicode 字模，实现中文界面显示；
传感器：DHT11 温湿度传感器（单总线时序读取）、MPU6050 六轴传感器（水平仪模式）；
音频：BT301M 蓝牙音频模块（USART + AT 指令）+ PAM8403 功放；
电源与电量：MAX17048 电量计（I2C 通信，实时监测电池电量与充放电状态）；
人机交互：多个独立按键 + 屏幕背光（PWM 调光）；
时钟：STM32 内置 RTC + 32.768kHz 外部晶振 + 后备电池（VBAT），实现断电走时。

## 三、软件设计
基于 Keil MDK + 标准外设库，采用"驱动层 / 应用层"分层模块化开发：

LCD 与界面：SPI 驱动彩屏，基于 W25Q64 外置字库完成中文与 Unicode 字符显示，搭建"蓝牙 / 时间 / 显示"多级设置菜单；
蓝牙音频：USART 与 BT301M 模块进行 AT 指令通信，实现播放/暂停、上下曲、音量调节及歌词同步显示；
RTC 时钟：配置 LSE 外部晶振、备份域寄存器，实现断电走时与 CST（东八区）时区换算；
传感器驱动：单总线时序驱动 DHT11 采集温湿度；I2C 驱动 MAX17048 读取电量；
按键与背光：EXTI 外部中断实现多按键长短按识别；TIM PWM 实现背光亮度调节与自动息屏；
电源管理：通过 PMOS 控制外部电源，配合 STM32 待机模式实现软关机与低功耗。

## 四、主要功能
实时时钟显示，掉电不丢时间；
温湿度实时采集与显示；
蓝牙连接手机播放音乐，支持播放控制与歌词显示；
电池电量实时监测与显示；
水平仪模式（基于 MPU6050）；
屏幕亮度可调、自动息屏；
中文图形界面与多级设置菜单。
